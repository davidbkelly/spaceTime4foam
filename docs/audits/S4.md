## Numerics (own derivation)

- **Edge orientation and flux.** Edges are stored as (min, max), and
  `n[edgei]` points from start to end (S3). The flux at
  `vertexCentred.C:414-418` is
  `0.5 lambda (uL + uR) - 0.5 |lambda| (uR - uL)`. For lambda > 0 this is
  lambda uL, and for lambda < 0 it is lambda uR, so it is upwind.
  `Res_j += Phi |n|` and `Res_k -= Phi |n|` give the outflow from j.
  Eq. 97 as printed gives lambda uR for lambda > 0, which is downwind.
  The comment about that typo is correct.
- **Reconstruction** (`:405-409`): uL uses grad_j and +0.5 d, and uR
  uses grad_k and -0.5 d, with d = x_k - x_j. This matches Eqs. 93-94.
  `gradient(u)` uses the computed u.
- **Weak closure** (`:198-236`):
  - Each node gets area 0.5 |n_B|.
  - The edge is inflow when A . n_B < 0.
  - The flux is the same upwind form with the interior state u_m and the
    exterior state u_b. For lambda < 0 it gives lambda u_b, and for
    lambda > 0 it gives lambda u_m, so it is consistent.
  - Corner nodes get one contribution per edge.
  - Because the form is upwind, using the exact state on outflow too
    changes nothing. Fault F6 gives bit-identical results.
- **Strong closure**: boundary nodes are not unknowns. They hold the
  exact value from initialisation, are never updated, and have their
  residual set to zero (`:429-435`).
- **Source**: `Res -= f V` (`:194`). This matches Eq. 100 with
  `div(Au) = f`. The base class gives `f = A . grad(u_exact)`, which
  matches f1 = 3(x + y), f2 = 6x + 10y and f3 = 2k exp(k(x + y)), with
  k = 0.1 by default.
- **RK2** (`:459-505`) uses Res(u*) in stage 2. On mesh 0, from the exact
  start, one step gives error 0.18142 = 0.55 (1 - g) with g = 0.67014.
  That is 1 + z + z^2/2 with z = -(0.75)(5/9), the Heun factor. Res(u^n)
  would give g = 1 + z = 0.583.
  - Both readings have the same fixed point. Fault F11 changes the norms
    by 3e-9 relative only, but takes 1190 instead of 583 iterations for
    VC-2 at N = 128.
  - Heun is the standard two-stage RK, so Res(u*) is the right reading.
- **Pseudo-time step**: D_j = sum 0.5 |n_jk . A| (Eq. 103), plus
  0.5 |n_B . A|/2 per boundary edge for weak closure. Removing that term
  (F10) changes the norms by at most 5e-10 relative. Iteration counts
  then fall slightly, for example from 583 to 577.
- **Convergence**: the RMS of Res/V over the unknowns, computed on the new
  solution. A non-finite value is fatal.

## Error measures

- The norms are weighted by V_j and normalised by the sum of the weights.
  The subsets are all, interior and boundary nodes.
- t = T: the half-edge weights sum to the length of tEnd, which is 1.
  Because the norms are normalised, only relative weights matter.
- nUnknowns is the number of nodes for weak closure and of interior nodes
  for strong.
- h = sqrt(A/(nTri/2)):
  - it is 1/N on the N x N benchmark meshes for both methods, so CCFV and
    VCFV are consistent on the same mesh;
  - it is 0.707/2^n on the Tufillaro meshes. The Table 2 script prints
    the paper's 1/2^n itself, and observed orders do not depend on a
    constant factor.
  - Not a problem for S5. The guide should state the definition when it
    quotes Table 2.
- The iteration-error check compares every norm column (CCFV 6-20,
  VCFV 6-17) as `%.3e` strings, as its header says.

## Rand48

- `Rand48.H` (v2412): `operator()` returns `engine_() >> 17`, and
  `max()` is 0x7FFFFFFF, so the output has 31 bits. x = r/2^31 is exact,
  and 2x - 1 is exact (a multiple of 2^-30 in [-1, 1)). So d = m s is
  one rounded product.
- Independent C++ (`auditS4/rand/lcg2.cpp`, a hand-written 48-bit LCG,
  no OpenFOAM): (x0 + d) - x0 reproduces all ten stored values bit for
  bit, for points 64-68 at x0 = 0.125 and t0 = 0.125 to 0.625.
- `pointsChecksum` starts at the first all-digit line (the list size), so
  it leaves out the FoamFile header, the banner and the arch line. The
  test passes with `d76c6410...`.

### Convergence-measure check

`Test-vertexCentredResidual -writtenResidual` reads the written u and
calls `calcResidual`. It forms the RMS of Res/V itself, over all nodes

shares the residual, which `-reference` verifies. It runs on both the
not-converged and the converged case.
