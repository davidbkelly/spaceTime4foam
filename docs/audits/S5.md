## Key finding: gradient consistency (reproduction)

Method (scratch only, Python used, stated as required):

- Meshes from the tutorial `Allmesh N left` and
  `Allmesh N left perturbed 12345`.
- `writeCellCentres`, then a scratch Python script wrote
  `u = x + 2t` at the cell centres and as `fixedValue` at every
  boundary face centre.
- The gradient came from `postProcess -func 'grad(u, result=gradU)'`.
  The `cache { grad(u); }` entry in the tutorial `fvSolution` makes
  that function object abort, so I removed it in the scratch copies
  only.
- Interior means a cell centre more than 2h from every boundary.

Maximum interior |grad(u) - (1, 2)|:

| N   | struct. Gauss | struct. LSQ | pert. Gauss | pert. LSQ |
| --- | ------------- | ----------- | ----------- | --------- |
| 16  | 1.6e-14       | 9.6e-15     | 0.720       | 1.0e-14   |
| 32  | 6.0e-14       | 2.4e-14     | 0.804       | 2.7e-14   |
| 64  | 1.2e-13       | 4.0e-14     | 0.948       | 7.1e-14   |
| 128 | 2.4e-13       | 1.0e-13     | 1.056       | 1.4e-13   |

On the perturbed meshes, the RMS interior `Gauss linear` error is 0.19,
0.22, 0.22 and 0.22. This is O(1) and does not decrease with N. Over all
cells, `leastSquares` is 0.72 (structured) and 1.16 to 1.32 (perturbed),
which is the known normal-only boundary offset in the boundary cells.

Mechanism (v2412 source):

- `fvMesh/fvGeometryScheme/basic/basicFvGeometryScheme.C`, lines
  121-126, sets the weights to
  `w = |Sf.(C_N - Cf)| / (|Sf.(Cf - C_P)| + |Sf.(C_N - Cf)|)`. This
  places the interpolated value where the segment P-N crosses the face
  plane, not at the face centroid. There is no skewness correction.
- `gaussGrad.C` (`calcGrad`, `gradf`) computes
  `grad = (1/V) sum Sf u_f`.
- On a skewed triangle the crossing point is O(h) away from the face
  centroid, so for a linear field u_f has an O(h) error. Each face then
  adds O(h) x |Sf| = O(h^2) to the sum, and dividing by V = O(h^2) gives
  an O(1) gradient error.
- On the structured Left meshes the P-N segments cross the faces at
  their centroids, so the gradient is exact to round-off.
- `linearUpwind` then reconstructs `u_P + grad_P . (Cf - C_P)` with an
  O(1) gradient error. The face values have an O(h) error, so CC-2 and
  CC-2-EX are first order.
- CC-2-LS differs from CC-2 only in the gradient and recovers L1 order
  2, which supports the causal claim.
- Possible remedies for the guide: `skewCorrected linear` interpolation
  in the gradient, or `leastSquares`. CLAUDE.md requires that numerics
  are not changed silently, so either is the developer's choice.
