# References

The papers used by spaceTime4foam are listed below. The PDF files are kept in
this directory locally but are **not tracked** by git (see `.gitignore`);
place your own copies here using the filenames given.

## Tufillaro, Williams and Nishikawa (2026)

Tufillaro, N., Williams, D. M. and Nishikawa, H., "Edge-Based Discretizations
on Triangulations in Any Dimension, With Special Attention to Four-Dimensional
Space", *International Journal for Numerical Methods in Fluids*, 2026,
pp. 1–22, doi:10.1002/fld.70084. Open access (CC BY). Received 22 October
2025, accepted 28 May 2026.

- Expected file: `refs/TufillaroWilliamsNishikawa.pdf`
- Used for: median-dual geometry, directed-area vectors, and the scalar
  advection verification in 2D, 3D and 4D.

## Padway and Nishikawa (2022)

Padway, E. and Nishikawa, H., "An Adaptive Space-Time Edge-Based Solver for
Two-Dimensional Unsteady Viscous Flows", AIAA SciTech 2022 Forum, 2022.
The copy of the paper in this directory does not print an AIAA paper number,
so none is given here.

- Expected file: `refs/PadwayNishikawa.pdf`
- Used for: space-time flux splitting, the time-aligned-edge fix and the
  pseudo-time solver.

## Possible later addition

Nishikawa, H., *Journal of Computational Physics*, 281:518–555, 2015. Cited by
